# 固定步长真实误差方向实验分析

## 实验有效性

实验完整结束，共使用32张固定图像，测试 ViT-S 第 0、3、5、8、11 块的 Attention
和 MLP。全局固定 `epsilon=1e-3`、固定四组、随机种子3407。总诊断时间为147.31秒。
真实误差方向的最大重构相对误差为 `4.28e-8`。

## 单方向与固定四组

对于同一个误差 `delta`，完整四组二次型和单方向二次型在数学上均为
`delta^T F delta`。JVP 实测两者的平均相对差异只有 `2.34e-7`，最大差异
`2.12e-6`。有限差分的平均差异为0.113%，95分位数为0.155%；唯一较大的差异来自
block0 MLP 的同一个离群样本。

四组方案没有增加目标信息，却把汇总后的前向计算时间从0.276秒增加到0.819秒，约为
单方向的2.97倍。因此固定四组应当停止，后续只保留单方向。

四组对角近似在10个模块中的9个模块上比完整二次型更差。block8 MLP 的对角预测 RMSE
为72.37%，而完整方向为17.23%。这说明跨通道项确实重要，但沿真实误差进行一次方向
查询已经自动包含这些交叉项，无需显式构造 Fisher 矩阵。

## 突破口：前向割线方向因子

下一步不再继续估计完整 Fisher。使用原始 FIMA-Q 已经保存的量化误差方向，并用一次
真实前向 KL 为该方向赋予有限位移曲率。对于块输出误差 `d` 和对应真实输出 KL `L`，
构造：

```
u = d / ||d||
g_forward = sqrt(L) * u
```

在原始 DPLR 的单方向形式中：

```
loss(e) = (e @ g_forward)^2 / (d @ d)
```

当候选误差 `e=d` 时，该损失严格等于真实前向 KL `L`。它是一个正半定、rank-1、
有限位移匹配的割线曲率代理。它不需要 backward，不需要完整 Fisher，也不需要任何
自适应选择。

这个方案可以直接对应 `utils/block_recon.py` 的现有数据结构：代码已经保存
`block.delta_out`、按固定 `k=5` 更新，并用 `inverse_B` 组合低秩方向。需要替换的是
`new_fisher_ro()` 中通过 `loss.backward()` 得到 `raw_grad` 的部分：改为前向 KL 加权
的误差方向因子。后续局部重建损失仍然可以反向优化量化参数，但 Fisher/曲率信息的
获取不再需要全模型反向传播。

## 下一项必要验证

在接入完整训练前，先增加一个固定实验：沿同一真实误差方向测试
`t={0.5, 0.75, 1.0, 1.25, 1.5}`。比较局部 Fisher 二次型和前向割线因子对不同幅度
真实 KL 的预测，重点观察第0块。如果割线方向在第0块显著改善，同时保持中后层排序，
就进入 `block_recon.py` 的固定 `k=5` 集成实验。

以上过程没有逐层步长、动态rank、动态分组或门控机制。
