## 四项因素拆分

| 对照 | Top-1 差值 pp | 本设置下的含义 |
|---|---:|---|
| C_mse - B_mse | +0.032 | MSE 短预校准下增加完整学习旋转的效果很小，仅净增 16 张验证图 |
| C_dplr - B_dplr | +0.088 | DPLR 短预校准下增加旋转的效果为小幅正值 |
| B_dplr - B_mse | -0.282 | 没有额外旋转时，当前 DPLR 短预校准弱于 MSE |
| C_dplr - C_mse | -0.226 | 有额外旋转时，当前 DPLR 短预校准也弱于 MSE |
| 旋转与损失的差分交互 | +0.056 | 两个小幅旋转收益之差，不能据此声称强机制 |

现有数据更支持“当前 DPLR 短预校准目标整体不如 MSE”，不支持把旧 C 下降归咎于学习旋转。
这是针对新增短阶段的估计器、归一化与权重实现的实验结果；所有方法后续正式重建仍用 DPLR，
不能据此声称正式 FIMA-Q 的 DPLR 无效。

在统一 DPLR 预校准下，A→B→C = 64.520→64.444→64.532；相对 A 增加 D 和 U 合计仅 +0.012 pp。
旧 C v1 = 64.240，修复后的 C_dplr = 64.532，版本复验提升 +0.292 pp。
零点网格问题有独立数值检查支持，但两次完整运行的每一点差值不能精确归因于单一修复。

## 低维与门槛

低维有界旋转相对完整 C_dplr 仅 +0.056 pp，仍低于历史固定旋转和两个 MSE 候选。
每块可训练参数由 24972 降到 3468，但不能根据当前不同批次、不同 GPU 竞争下的墙钟时间宣称加速。
低维版本的 Top-5 和验证 loss 较好，不能将它们等同于用户关注的 Top-1 改善。

5% 门槛使低维版本下降 0.212 pp。接受块数由 7 变为 4，并未转化为更高准确率。
无门槛接受块为 1、4、5、6、7、8、10；有门槛为 1、2、3、8（从 0 编号）。
二者不是简单的子集关系，门控改变后续量化前缀和逐块候选路径，因此不能把结果解释为单纯删除三个块的效果。
当前不支持继续增大这个门槛。

## 阶段失配的证据边界

舍入后探针是同一校准图片上的教师 KL，且后续块仍为浮点；这些图片也参与正式重建。
它没有给出同一候选在两条完整 AdaRound 路径中的配对反事实，不能直接证实“预校准与舍入脱节”是主因。
同阶段旋转与舍入联合优化仍是可测试的后续假设，尚未实现或取得准确率结果。

## 研究取舍

保留固定 Hadamard 作为可靠参照；记录 C_mse 的最高 Top-1，并保留更简单的 B_mse。
C_mse 相对 B_mse 仅 +0.032 pp，目前不能支撑额外学习旋转是强核心贡献；相对历史固定仅 +0.108 pp，也未建立稳定性。
本轮七项没有产出可靠的大幅新增益，不能作为已经成功提分的强论文结果。

不建议继续围绕 DPLR 预校准、rank 和固定接受门槛大范围搜索。
若继续开发学习旋转，优先考虑把旋转与 AdaRound 舍入放入同一个实际量化重建阶段；
需要先解决变换、量化网格及 rounding 参数随旋转变化的一致性，再评估完整 Top-1。
该建议是针对现有训练流程的研究假设，不能保证有效。低维旋转在 MSE 下尚未测试，也不能从当前 DPLR 结果断言其必然失败。
